# Anonymous Artifact Checklist

Before linking this repository from a double-anonymous submission, verify the following:

- [ ] The repository URL does not reveal author identity, institutional affiliation, or personal account names.
- [ ] Commit history, README text, paths, and metadata do not reveal author identity.
- [ ] No API keys, tokens, `.env` files, or local absolute paths are present.
- [ ] Private mapping files are not public.
- [ ] Annotator-facing files contain no condition labels, heuristic scores, expected-action fields, or potential-harm summaries.
- [ ] Generated `__pycache__` directories are removed.
- [ ] Raw run outputs are included only if checked for secrets and anonymization.
- [ ] Any human-validation material uses anonymized validator IDs.
- [ ] IRB/ethics status is described at an appropriate level of detail without identifying authors or institutions.
